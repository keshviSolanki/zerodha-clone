# Zerodha Clone

A Zerodha-inspired trading platform clone built using React, Node.js, Express, and MongoDB.

## Features

- Trading platform UI
- Dashboard
- Responsive design
- Backend API
- MongoDB integration

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB

## Project Structure

- `frontend/` – React frontend
- `backend/` – Node.js/Express backend
- `dashboard/` – Dashboard UI

## How to Run

### Frontend

```bash
cd frontend
npm install
npm run dev
